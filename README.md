# Coding Ninjas Studio Solutions

Solutions to contests, challenges, and individual problems from Coding Ninjas Studio (now Naukri Code 360).

## Layout

- **`Contests/`** — Weekly Weekend Contests, CODEHUSTLE, Striver Array Contest, and others
- **`Challenges/`** — multi-day events like 21 Days DSA Challenge, Coding World Cup, Ninja Dominator, PrepTrain "6 Companies — 15 Days"
- **`Codekaze/`** — Codekaze rounds (e.g. October Round 2)
- **`Problems/`** — standalone problems, including Interview Series

## Languages

Primarily C++ and Java.
